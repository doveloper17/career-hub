# 로컬 작업 기록

빈 양식입니다. `npm run worklog:init`으로 `.local/WORK_LOG.md`를 만든 뒤 그 파일에만 실제 이력을 작성합니다.

## 현재 목표와 완료 조건

이번 사용자 요청과 검증 가능한 완료 조건을 기록한다.

## 순서별 체크리스트

- [ ] 1. 현재 코드·문서·사용자 요청 확인
- [ ] 2. 이번 작업의 구현 순서와 완료 조건 구체화
- [ ] 3. 구현 및 단계별 검증
- [ ] 4. 결과·남은 작업·재개 지점 기록

## 단계별 변경과 검증

변경 파일, 수행 내용, 실행 명령과 성공/실패 결과를 단계마다 기록한다. 비밀정보와 사용자별 절대 경로는 기록하지 않는다.

## 다음 재개 지점

다음 미완료 작업, 필요한 사용자 입력, 실패 이유, 프로젝트 루트 기준 명령을 기록한다.

이력서 실행기를 사용했다면 대상 지원 ID와 사람의 결정만 연결한다. `npm run workflow -- handoff ID`로 상태·현재 진단·다음 행동을 읽으며 단계·사용량을 수동 복사하지 않는다. 실제 체크포인트는 `.local/workflow-runs/ID/state.json`, 자동 요약은 같은 폴더의 `handoff.md`다. 원본 사실·승인을 이 요약이나 작업 일지로 대체하지 않는다. 개발 변경·검증과 실행기 밖 미완료 작업은 이 일지에 남긴다. .local을 잃으면 실행 기록도 사라지므로 비공개 백업을 유지한다.

## 이번 작업의 결정과 승인

확인한 사실과 사용자 승인 범위를 기록한다. 승인받지 않은 작업을 승인으로 표시하지 않는다.
